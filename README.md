# GPT Backend

A Node.js backend project that integrates an external AI API to build AI-powered applications.

## Tech Stack

* Node.js
* JavaScript
* Express.js
* Google Gemini API
* MongoDB

## AI Integration

This project uses the **Google Gemini API** to process prompts and generate AI responses.

## Getting Started

### Clone the repository

```bash
git clone https://github.com/deepanshu749/gpt-backend.git
cd gpt-backend
```

### Install dependencies

```bash
npm install
```

### Environment Variables

Create a `.env` file in the root directory:

```env
GEMINI_API_KEY=your_api_key_here
```

Never commit your `.env` file or expose your API key publicly.

### Run the project

```bash
npm run dev
```
